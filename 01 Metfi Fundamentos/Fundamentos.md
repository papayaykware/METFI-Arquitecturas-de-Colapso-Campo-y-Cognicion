# 01 · METFI — Fundamentos

## Rol del módulo

Este directorio constituye el **primer desarrollo formal** del repositorio. Aquí se define **METFI** como modelo físico–planetario operativo, estableciendo sus postulados mínimos, su lógica interna y sus diferencias irreductibles respecto a los marcos geofísicos estándar.

Si el módulo `00_Introduccion_y_Marco` fija las reglas del juego, este documento introduce el **sistema** que se jugará bajo ellas.

---

## Definición operacional de METFI

**METFI (Modelo Electromagnético Toroidal de Forzamiento Interno)** describe la Tierra como un **sistema electromagnético toroidal**, dinámico y no lineal, cuyo comportamiento macroscópico emerge del **forzamiento interno** y de la **ruptura progresiva de simetrías de campo**.

METFI no es una metáfora geométrica ni un modelo descriptivo ampliado: es una **arquitectura funcional** orientada a explicar fenómenos acoplados que los modelos desacoplados no logran integrar.

---

## Postulados fundamentales

1. **La Tierra como sistema de campo**
   El planeta se modela prioritariamente como una distribución de campos electromagnéticos acoplados, no como un conjunto de capas mecánicas aisladas.

2. **Topología toroidal dominante**
   La geometría funcional del sistema es toroidal, con circulación de energía, carga y momento a través de bucles cerrados.

3. **Forzamiento interno endógeno**
   La dinámica global se rige por procesos internos acumulativos, no por excitaciones externas episódicas.

4. **No linealidad estructural**
   Pequeñas variaciones internas pueden producir transiciones de fase abruptas a escala planetaria.

5. **Ruptura de simetría como condición de evento**
   Los eventos geofísicos extremos emergen cuando el sistema pierde coherencia toroidal.

---

## Diferencias con modelos convencionales

| Enfoque estándar      | METFI                   |
| --------------------- | ----------------------- |
| Capas mecánicas       | Campos acoplados        |
| Forzamiento externo   | Forzamiento interno     |
| Linealidad aproximada | No linealidad dominante |
| Eventos aislados      | Transiciones de fase    |
| Geometría implícita   | Topología explícita     |

METFI no pretende reemplazar modelos locales, sino **explicar sus fallos de integración global**.

---

## Componentes estructurales del modelo

* **Campo toroidal interno**: bucle principal de circulación energética.
* **Gradientes de carga y potencial**: acumulación y descarga no homogénea.
* **Acoplamiento núcleo–manto**: mediado por estructuras de campo, no solo por mecánica.
* **Pérdida de coherencia**: transición de régimen estable a caótico.

Estos componentes se desarrollan formalmente en los módulos posteriores.

---

## METFI y eventos de desacoplamiento

Dentro de este marco, fenómenos como el **ECDO (Exothermic Core–Decoupling Oscillation)** se interpretan como **manifestaciones críticas** de una pérdida de simetría toroidal.

El evento no es el origen del problema, sino su **expresión terminal**.

---

## Alcance y límites

### Alcance

* Integración de geofísica, electromagnetismo y sistemas complejos.
* Marco unificado para eventos planetarios abruptos.
* Base para extensiones biológicas y cognitivas.

### Límites

* No optimizado para predicción puntual a corto plazo.
* Requiere datos interpretados desde una lógica de campo.
* Incompatible con aproximaciones puramente estadísticas sin estructura.
